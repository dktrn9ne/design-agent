# Voice

Lead with the useful system, the research question or the evidence. Keep the human and
operational context visible. The public studio line is “Culture builds better tech.”
Use “Grounded in evidence” as a principle, not a claim that every prototype is validated.

Copy supplied for a project is exact. Do not invent customer results, revenue, funding,
partners, endorsements, production status or project ownership. Use a dated claim ledger.
Explain technical work with concrete actions and outcomes. Prefer one clear message per frame.
See sources.md for the public source and studio-context.md for project boundaries.
