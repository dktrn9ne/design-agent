# Graphic language

The current website uses editorial white surfaces, blue calls to action, oversized serif
headlines, plain sans-serif copy, restrained rules and dark navy flagship panels. Use those
relationships across social, decks and event materials. Real product UI is the focal evidence.

Use tokens.css for every color and font. Light: paper ground, ink headlines, muted secondary
copy, signal accent. Dark: navy ground, paper headlines, slate secondary copy and blue-pale
accent. Line is a divider, never small text. Measure contrast for each actual combination.

Portable fonts: Fraunces replaces Georgia for display; Inter replaces Arial for body; Fragment
Mono replaces the generic monospace. These are declared production fallbacks, not approved
original brand fonts. They are already bundled with OFL licenses. No licensed font is copied.

Logos: the original website images are preserved byte-for-byte. The SVG wrappers reproduce
its viewBox crops and embed those same bytes for offline use; they are not vector redrawings.
Use on white/light grounds. No reversed version was supplied: do not invert or recolor. For a
dark layout, place the original lockup in a white panel or request official reversed artwork.

Draft production defaults, not sourced brand rules: -0.02em display tracking for Fraunces (the website uses tighter Georgia tracking), square corners, 8 px spacing unit,
2 px diagram strokes, 160 px minimum lockup and 48 px minimum mark. Confirm physical sizes,
clear space, bleed, ink and vendor templates before printing. A merchandise mockup is a concept.

Open questions for brand-owner review: approve the portable fonts and production defaults;
provide vector masters, reversed logo and print standards when available. No asset from the
previous expo/booth concept was supplied, so this pack does not claim to reproduce it.
